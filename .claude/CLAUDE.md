# pink-orchestrator

System tray manager for pink-tools services.

```bash
{{PINK_TOOLS}}/pink-orchestrator/pink-orchestrator                             # Start in system tray
{{PINK_TOOLS}}/pink-orchestrator/pink-orchestrator --health                    # Check health
{{PINK_TOOLS}}/pink-orchestrator/pink-orchestrator --version                   # Show version
{{PINK_TOOLS}}/pink-orchestrator/pink-orchestrator --update-all                # Update all installed services
{{PINK_TOOLS}}/pink-orchestrator/pink-orchestrator --service-update <name>     # Update a service
{{PINK_TOOLS}}/pink-orchestrator/pink-orchestrator --service-restart <name>    # Restart a service
{{PINK_TOOLS}}/pink-orchestrator/pink-orchestrator --service-stop <name>       # Stop a service
{{PINK_TOOLS}}/pink-orchestrator/pink-orchestrator --service-start <name>      # Start a service
```
